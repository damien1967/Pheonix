# Core User

> Placeholder — flesh out once the game concept solidifies.

We are building this app with an actual person in mind, not a demographic. That person is **Stephen Fry**.

Designing for one specific, real person forces concrete decisions instead of vague "broad appeal" thinking. When a design or copy choice is ambiguous, the test is: would this feel right to Stephen Fry?

Rough starting notes — expand later:
- Sharp, well-read, values wit and precision over noise
- Enjoys language, wordplay, and elegant systems
- Has no patience for anything patronising or dumbed-down
- Comfortable with technology, early-adopter instincts
